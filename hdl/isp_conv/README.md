# isp_conv

`isp_conv` is the linear kernel of OpenISP: it multiplies every pixel of a window of `isp_window` by a signed
coefficient and outputs the sum as one pixel, at full precision or limited to `OutBits_g` bits, with negative sums set
to 0. The size of the window is set by generics; the coefficients are set by a generic or, as an option, by registers
on an AXI4-Lite slave at run time, parity-protected and taken at the start of an image. It has no memory.

## Tests

Prerequisites: those of the repository (GHDL, the Python packages of `requirements.txt`, the submodules).

```shell
python run.py -p 4 "*isp_conv*"                                  # all tests in all configurations
python run.py -v "*isp_conv_tb.mtf3.test_parity"                 # one test with its log
```

| File | Content |
| --- | --- |
| `src/isp_conv.vhd` | The module |
| `src/isp_conv_regs_pkg.vhd` | Register addresses and fields, generated by `tools/regmap.py` from `regs/isp_conv_regs.yml` |
| `regs/isp_conv_regs.yml` | Register description |
| `tb/isp_conv_tb.vhd` | Testbench: the module with the coefficient set of the generic as a string (`ispIntList`), the shared source and sink, the register script on the AXI4-Lite BFM of UVVM, the count of the `Err_Config` pulses, the monitor of the control outputs and of the output pixels, the latency check of test_rate and the flag sweep of test_flag_coincidence |
| `tb/vunit_config.py` | Configurations, the window stream and the register script of every test; runs the reference model `conv` (class `ConvKernel`) of `tools/isp_model.py` |
| `../../lint/isp_conv_synth.vhd` | Wrapper for `lint/synth_check.py`: builds the coefficient set from integer generics, which GHDL can set on the command line |

The shared components (`tb/isp_tb_source.vhd`, `tb/isp_tb_sink.vhd`, `tb/isp_tb_axilite_pkg.vhd`,
`tools/isp_model.py`, `tools/isp_tbgen.py`) are described in the [testbench components](../../docs/testbench.md).
