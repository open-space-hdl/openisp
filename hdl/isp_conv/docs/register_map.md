# isp_conv: Register Map

Generated by `tools/regmap.py` from `hdl/isp_conv/regs/isp_conv_regs.yml`, do not edit. The same description generates
the VHDL package `isp_conv_regs_pkg` and the C header `sw/isp_conv_regs.h`; `tools/regmap.py --check` compares it with
the register table of the [specification](specification.md#7-register-map).

Registers of the linear kernel: identification, characteristics, control, status, error injection and the coefficients
(read only with RuntimeCoef_g false). Byte addresses of 32-bit registers on the AXI4-Lite slave (12-bit address); unused
addresses and bits read as zero, and every access is answered with OKAY.

| Access | Meaning |
| --- | --- |
| RO | Read only |
| RW | Read and write |
| W | Write only, the argument of a command; reads as zero |
| W1 | Write one: command; reads as zero |
| W1C | Sticky flag; write one to clear |

## Registers

| Address | Register | Description |
| --- | --- | --- |
| 0x00 | [ID](#id) | Identification |
| 0x04 | [PARAM](#param) | Characteristics |
| 0x08 | [CTRL](#ctrl) | Control |
| 0x0C | [STATUS](#status) | Status |
| 0x10 | [INJECT](#inject) | Error injection for the test of the error handling |
| 0x100 + 4 x k | [COEF](#coef) | Coefficient of element k |

COEF[k], k = 0 to T - 1 (T = WinX_g x WinY_g), at 0x100 + 4 x k.

| Bits | Field | Access | Reset | Description |
