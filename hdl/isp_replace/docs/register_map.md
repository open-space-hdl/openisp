# isp_replace: Register Map

Generated by `tools/regmap.py` from `hdl/isp_replace/regs/isp_replace_regs.yml`, do not edit. The same description
generates the VHDL package `isp_replace_regs_pkg` and the C header `sw/isp_replace_regs.h`; `tools/regmap.py --check`
compares it with the register table of the [specification](specification.md#7-register-map).

Registers of the pixel replacement: identification, dimensions, the defect map and its status. Byte addresses of 32-bit
registers on the AXI4-Lite slave (8-bit address); unused addresses and bits read as zero, and every access is answered
with OKAY.

| Access | Meaning |
| --- | --- |
| RO | Read only |
| RW | Read and write |
| W1 | Write one: command; reads as zero |
| W1C | Sticky flag; write one to clear |
| WO | Write only; reads as zero |
