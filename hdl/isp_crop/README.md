# isp_crop

`isp_crop` selects a rectangular region of interest of an image: it takes the pixel stream of an image of
`ImageWidth_g` x `ImageHeight_g` pixels and outputs a region of `RoiWidth_g` x `RoiHeight_g` pixels as an image of
its own. The position of the region is set by generics or, as an option, by a register at run time. Its
input is an [`isp_frame_sync`](../isp_frame_sync/README.md); its registers are on an AXI4-Lite slave. It has no memory.

## Tests

Prerequisites: those of the repository (GHDL, the Python packages of `requirements.txt`, the submodules).

```shell
python run.py -p 4 "*isp_crop*"                                  # all tests in all configurations
python run.py -v "*isp_crop_tb.w8_h6_runtime.test_parity"        # one test with its log
```

| File | Content |
| --- | --- |
| `src/isp_crop.vhd` | The module |
| `src/isp_crop_regs_pkg.vhd` | Register addresses and fields, generated by `tools/regmap.py` from `regs/isp_crop_regs.yml` |
| `regs/isp_crop_regs.yml` | Register description |
| `tb/isp_crop_tb.vhd` | Testbench: the module, the shared source and sink, the register script on the AXI4-Lite BFM of UVVM, the counts of the `Err_Framing` and `Err_Config` pulses, the monitor of the control outputs, the timing checks of test_rate and the sweeps of test_flag_coincidence |
| `tb/vunit_config.py` | Configurations, the stimulus and the register script of every test; runs the reference model `crop` of `tools/isp_model.py` |

The shared components (`tb/isp_tb_source.vhd`, `tb/isp_tb_sink.vhd`, `tb/isp_tb_axilite_pkg.vhd`,
`tools/isp_model.py`, `tools/isp_tbgen.py`) are described in the [testbench components](../../docs/testbench.md).
