# isp_point

`isp_point` is the pixel-level operation of OpenISP: it adds a signed offset to every pixel, multiplies by an unsigned
gain, shifts the product right and clamps the result between a lower and an upper threshold. The parameters are set
by generics or, as an option, by registers on an AXI4-Lite slave at run time. Its input is an
[`isp_frame_sync`](../isp_frame_sync/README.md). It has no memory.

## Tests

Prerequisites: those of the repository (GHDL, the Python packages of `requirements.txt`, the submodules).

```shell
python run.py -p 4 "*isp_point*"                                 # all tests in all configurations
python run.py -v "*isp_point_tb.runtime.test_hold"               # one test with its log
```

| File | Content |
| --- | --- |
| `src/isp_point.vhd` | The module |
| `src/isp_point_regs_pkg.vhd` | Register addresses and fields, generated by `tools/regmap.py` from `regs/isp_point_regs.yml` |
| `regs/isp_point_regs.yml` | Register description |
| `tb/isp_point_tb.vhd` | Testbench: the module, the shared source and sink, the register script on the AXI4-Lite BFM of UVVM, the counts of the `Err_Framing` and `Err_Config` pulses, the monitor of the control outputs, the latency check of test_rate and the flag sweeps of test_flag_coincidence |
| `tb/vunit_config.py` | Configurations, the stimulus and the register script of every test; runs the reference model `point` of `tools/isp_model.py` |

The shared components (`tb/isp_tb_source.vhd`, `tb/isp_tb_sink.vhd`, `tb/isp_tb_axilite_pkg.vhd`,
`tools/isp_model.py`, `tools/isp_tbgen.py`) are described in the [testbench components](../../docs/testbench.md).
