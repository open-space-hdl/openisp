# isp_point: Register Map

Generated by `tools/regmap.py` from `hdl/isp_point/regs/isp_point_regs.yml`, do not edit. The same description generates
the VHDL package `isp_point_regs_pkg` and the C header `sw/isp_point_regs.h`; `tools/regmap.py --check` compares it with
the register table of the [specification](specification.md#7-register-map).

Registers of the pixel operation: identification, dimensions and widths, control, status, error injection and the
parameter set (read only with Runtime_g false). Byte addresses of 32-bit registers on the AXI4-Lite slave (8-bit
address); unused addresses and bits read as zero, and every access is answered with OKAY.

| Access | Meaning |
| --- | --- |
| RO | Read only |
| RW | Read and write |
| W1 | Write one: command; reads as zero |
| W1C | Sticky flag; write one to clear |
