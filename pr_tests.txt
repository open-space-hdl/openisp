# Pull requests into develop run these tests (python run.py -p 4 --subset pr_tests.txt). The full regression runs on
# every push to develop, main and release/*, on pull requests into main and on a manual start of the workflow. The
# subset is a smoke test: the merge evidence of a module is the full local regression and the mutation run.
#
# Rules (python tools/ci_subset.py --check):
# - every test of every testbench runs in at least one configuration (checked);
# - every pattern matches at least one test (checked);
# - no configuration of the full tier: images of 65536 pixels per line or of 65536 lines, exhaustive_p6 (checked);
# - at least one configuration at the low bound of every generic of the module, every value of a boolean or an
#   enumeration (review).
